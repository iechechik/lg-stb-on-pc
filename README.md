# STB — приставка из мини-ПК

Набор скриптов и служб, которые превращают старый мини-компьютер (в моём случае
Intel NUC на i3-5010U) в приставку к телевизору LG на webOS.

Что внутри:

- лёгкий интерфейс — сетка плиток в браузере на весь экран, без рабочего стола;
- один демон постоянного соединения с телевизором (SSAP): состояние, кнопки,
  ввод, звук, громкость;
- пульт-приложение с телефона по Wi-Fi: приставка представляется телевизором LG
  и принимает кнопки, указатель и текст (Bluetooth — как дополнительный канал);
- сторожа: включение/выключение телевизора, лёгкий режим (powersave), звук,
  заставка по простою, гашение телевизора, WoL;
- плитки для домашних сервисов, Jellyfin на телевизоре и на приставке;
- установщик и сборщик дистрибутива, набор тестов (117 на сегодня).

## Это решение для себя

Проект написан под конкретную квартиру и конкретный телевизор. Здесь есть
допущения, которые у вас не совпадут: провод телевизора в отдельном сегменте
за вторым интерфейсом приставки, конкретные идентификаторы приложений LG,
подписи плиток по-русски, интеграция с Home Assistant только через WoL.

## Что нужно

- Debian 12/13, X11, openbox, Firefox ESR (всё ставится установщиком);
- телевизор LG webOS в той же сети;
- мини-ПК с HDMI.

## Установка

```sh
tar xzf stb-*.tar.gz
cd stb
sudo STB_USER=stbuser STB_TV_IP=192.168.1.199 STB_TV_MAC=aa:bb:cc:dd:ee:ff \
     STB_LAN_IF=wlp2s0 bash install.sh
```

`STB_LAN_IF` — интерфейс, через который виден телевизор (имя смотреть в
`ip -br link`; по умолчанию `wlp2s0`). Если телевизор подключён и по проводу, и по
Wi-Fi, второй MAC можно передать в `STB_TV_MAC_ALT`: по нему телевизор опознаётся,
когда просыпается по Wi-Fi.

Проверка без изменений: `bash install.sh --check`.
Тесты: `sudo sh tests/run_tests.sh` — часть из них читает `/etc` и службы, без
root они падают.

## Документация

- `docs/README.md` — обзор и первый запуск;
- `docs/SYSTEM.md` — устройство: службы, протокол демона, сторожа, журналы;
- `docs/COMMANDS.md` — все команды `stb` (генерируется из кода);
- `docs/INSTALL.md`, `docs/WEB.md`, `docs/Remote_Control_Setup.md` — установка,
  веб-слой и настройка пульта.

Ключ доступа к телевизору (`~/.aiopylgtv.sqlite`) в дистрибутив не входит —
он создаётся при первом сопряжении с телевизором.
