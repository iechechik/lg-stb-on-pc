# Приставка из мини-компьютера

Превращает компьютер на Linux в телевизионную приставку для телевизора LG. 
На экране телевизора — сетка плиток (Jellyfin, YouTube, *arr, браузер), 
управление с телефона по Wi-Fi или Bluetooth.

Проверено на: Intel NUC5i3 (i3-5010U, 8 ГБ), телевизор LG с web 4.0, телефон на  Android. Система — Debian 13.
Приложения 1) AirMouse от SAASWISE для WiFi 2) AirMouse BT от Quatech для BT

## Состав
```
install.sh        установка
bin/              программы: сторож stb-watch, демон телевизора, приёмник, утилиты
config/           настройки: параметры, карты кнопок, плитки
web/              страница сетки, страница кнопок, картинки плиток
lib/              общие функции, клиент демона телевизора, указатель XTest
system/           всё, что живёт вне /opt/stb: /etc и /usr (одно дерево)
home/             файлы пользователя: профиль браузера, openbox, службы пользователя
docs/             документация
```

Три фоновых процесса: `stb-watch` (девять сторожей в одном), `stb-tv-link` (одно соединение с телевизором) и `stb-wifi-remote` (приёмник пульта).

Установщик ставит пакеты (браузер, оконный менеджер, звук, Bluetooth, Python,
`python3-xlib` для указателя), плеер Jellyfin Desktop через Flatpak, библиотеку
`bscpylgtv` для управления телевизором; копирует скрипты, страницы и дерево
`system/` в `/etc`; настраивает автовход, сессию, кнопку питания и права sudo;
включает все службы и проверяет, что каждая обязательная программа на месте.
Ошибка на любом шаге останавливает установку — «✓» без выполнения не бывает.

## Установка

```sh
tar xzf stb-YYYYMMDD.tar.gz          # распаковать целиком
sudo STB_TV_IP=<адрес телевизора> STB_TV_MAC=<MAC телевизора> bash stb/install.sh
```

Телевизор подключается к приставке кабелем. Установщик сам настраивает эту сеть:

- `dnsmasq` выдаёт телевизору постоянный адрес по его MAC
  (`/etc/dnsmasq.d/tv-lan.conf`, из шаблона `system/etc/dnsmasq.d/`);
- интерфейс телевизора получает адрес приставки и маршрут к нему
  (`/etc/network/interfaces.d/tv-lan`);
- на обоих интерфейсах включается `proxy_arp`
  (`system/etc/sysctl.d/90-tv-proxyarp.conf`).

Параметры: `STB_TV_IF_ADDR` (адрес приставки в сети телевизора),
`STB_GW` и `STB_DNS` (шлюз и DNS для телевизора) — если не заданы,
берутся из системы. Проверить полноту архива и доступность пакетов без
установки: `bash install.sh --check`.

После перезагрузки:

```sh
sudo stb tv register          # знакомство с телевизором, подтвердить на экране
sudo /opt/stb/bin/stb pair              # подключение телефона-пульта
tv powerstate                                 # состояние телевизора
```

## Как устроено управление телевизором

Телевизором занимается один демон `stb-tv-link`: одно постоянное соединение и
подписки на состояние. Кнопка, указатель, сторож телевизора и сторож звука
обращаются к нему через сокет `/run/stb/tv.sock` — нажатие занимает 40–70 мс.
Команда `tv` тоже ходит через демона, а если он недоступен — работает напрямую.

Приставка гасит телевизор сама, если её экран остаётся чёрным слишком долго:
5 минут до заставки плюс `STB_TV_SLEEP_AFTER` (по умолчанию 10) минут тишины.
В режиме телевизора заставки нет вообще — там это правило не работает.

## Сборка дистрибутива

```sh
sudo /opt/stb/makedist.sh --to-misc      # тесты, проверка архива, архив на misc
sudo /opt/stb/makedist.sh /tmp/stb.tar.gz
sudo /opt/stb/makedist.sh                # только обновить system/ и home/
```

Ключ телевизора в архив не кладётся (это секрет): после установки телевизор один
раз попросит подтверждение. Нужен готовый ключ — `--with-key`.

## Проверки

Тесты не требуют телевизора и графической сессии:

```sh
sudo /opt/stb/tests/run_tests.sh          # тесты + pyflakes + shellcheck
sudo /opt/stb/tests/bench_consumers.py    # замер: сколько стоит опрос
```

Файлы тестов собраны по темам — демон, сторож, отметки, формат журналов, окна,
карты кнопок, Back, WebSocket, ввод текста, приёмник, конфиг, плитки,
документы, качество исходников, установщик. Карта «файл — что проверяет» и
правила для новых тестов: `tests/README.md`.

`bench_consumers.py` поднимает поддельный телевизор (`tests/fake_tv.py`) и
показывает, сколько запросов, процессорного времени и процессов тратят
сторожа. Всё нужное для проверок (`python3-pytest`, `python3-pyflakes`,
`shellcheck`) ставит установщик — отдельно доустанавливать нечего.

## Команда `stb`

Всё делается одной программой. Запускать можно от пользователя приставки:

```sh
stb tv on | off | powerstate | status
stb tv key UP | stb tv up | stb tv vol 12 | stb tv mute
stb tv setinput HDMI_3 | stb tv app com.webos.app.browser
stb tv speakers | stb tv speaker external_arc

stb mode [nuc|tv]        режим пульта
stb toggle               приставка ↔ телевизор
stb live                 на телевизор, источник не меняется
stb box                  назад на приставку
stb jelly                Jellyfin на телевизоре
stb close                закрыть активное окно
stb sound on | off       звук приставки (на сетке глушится сам)
stb ui restart           перезапуск интерфейса: браузер и сетка заново
stb poweroff [--keep-tv|--dry-run|--now]   выключить телевизор, потом приставку

stb lang [ru|en|toggle|status]   раскладка клавиатуры
stb ctl [status|restart|stop|start]   службы
```

Имя `tv` — та же программа: `tv on` равно `stb tv on`.

## Управление службами

```sh
sudo stb ctl status     # таблица: запущена, включена
sudo stb ctl restart    # перезапустить весь комплекс
sudo systemctl restart stb.target    # системные службы (не пользовательские)
```

## Настройка

| Файл | Что содержит | Как применить |
|---|---|---|
| `/opt/stb/config/stb.conf` | адреса, имена, пороги | перезапустить службу |
| `/opt/stb/config/buttons-wifi.conf` | карта кнопок Wi-Fi | `sudo /opt/stb/bin/stb keys apply wifi` |
| `/opt/stb/config/buttons-bt.conf` | карта кнопок Bluetooth | `sudo /opt/stb/bin/stb keys apply bt` |
| `/opt/stb/config/tiles.json` | плитки на экране | ничего: страница перечитывает раз в минуту |

Комментарии в картах кнопок — отдельной строкой, начиная с `#`. В `tiles.json`
допустимы `//`, `/* */` и висячие запятые.

Пороги простоя в `stb.conf`:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `SCREENSAVER_MINUTES` | 5 | через сколько минут без нажатий включается чёрная заставка (только в режиме приставки) |
| `STB_TV_SLEEP_AFTER` | 10 | через сколько минут **после заставки** приставка гасит телевизор; `0` — не гасить |
| `IDLE_POWEROFF_AFTER` | 0 | выключение приставки после того, как погас телевизор, секунды; `0` — никогда |
| `GESTURES` | `BACK` | кнопки с выдержкой: двойное нажатие — отдельное событие, одиночное ждёт окно; вписать имя — и механизм работает для неё |
| `DOUBLE_BACK` | 1.0 | окно второго Back: в приложении — спрятать его и вернуться на сетку (место в приложении сохраняется), в режиме телевизора — вернуться на приставку |
| `POINTER_SPEED` | 0.35 | чутьё точпада: во сколько раз уменьшать шаг указателя |

Итого при умолчаниях: 5 минут до заставки, ещё 10 минут тишины — телевизор
выключается сам. Суммарно 15 минут от последнего нажатия. Выключение приставки
при этом не происходит: `IDLE_POWEROFF_AFTER` равен нулю.

## Пульт

| Канал | Приложение | Как работает |
|---|---|---|
| Wi-Fi | «AirMouse — Smart TV Remote» | приставка представляется телевизором LG и принимает кнопки, указатель и текст |
| Bluetooth | то же приложение в режиме клавиатуры | приставка видна как Bluetooth-клавиатура, нажатия перехватывает `xbindkeys` |

Карта кнопок переводит название кнопки в действие, действие выполняет
`stb key` с учётом режима: `nuc` — управление приставкой, `tv` —
телевизором. В режиме `tv` кнопки уходят прямо в демон телевизора, минуя
`stb key` (см. `lib/stbkeys.py`). Подробно — `docs/Remote_Control_Setup.md`.

Два нажатия значат больше одного: **Play/Pause** в приложении нажимает то, что
под указателем (на телефоне в режиме точпада нет OK, а Enter в Jellyfin бьёт по
прежнему фокусу), на сетке — запускает выбранную плитку, в режиме телевизора
уходит в телевизор. **Back**: одиночный отдаётся приложению, двойной за секунду
прячет окно и возвращает на сетку; в режиме телевизора двойной Back возвращает
на приставку.

## Звук

Звук приставки идёт в телевизор по HDMI, поэтому `volup`, `voldown` и `mute`
всегда управляют телевизором. Заглушка самой приставки переключается по
событиям: на сетке и в скрытом приложении — тишина, при запуске Jellyfin, сайта
или возврате в приложение — звук. Вручную: `stb sound on|off`.

## Выключение

`stb poweroff` сначала гасит телевизор и ждёт подтверждения (обычно 1–3 секунды,
не больше 20), и только потом приставку. Иначе оставшийся включённым телевизор
будит её обратно по сети — так и случалось ночью. Ключи: `--keep-tv` (телевизор
не трогать), `--dry-run` (показать, что будет сделано), `--now` (приставку без
ожидания). Плитки «Выключить ТВ», «Выключить приставку» и «Перезапуск
интерфейса» спрашивают подтверждение.

## Если что-то не работает

- **Пульт молчит.** Проверить подключение: `bluetoothctl info | grep Connected`;
  при необходимости открыть окно сопряжения (плитка «Добавить пульт»).
- **Кнопки доходят, телевизор не реагирует.** Проверить связь
  (`nc -z -w1 <IP> 3000`); если связи нет — сбросить линк:
  `sudo sh -c 'ip link set <интерфейс> down; sleep 2; ip link set <интерфейс> up'`.
- **Плитка «Телевизор» открыла не то.** Она возвращает то, что смотрели последним
  (`/var/lib/stb/tv-last`), а не эфир: после сетки телевизор стоит на нашем входе,
  и «оставить как было» показало бы ту же сетку. Пока памяти нет — откроется
  `TV_FALLBACK_APP`. Поменять: `TV_FALLBACK_APP`, `TV_RESTORE_LAST` в `stb.conf`.
- **Телевизор показывает не то.** Вход HDMI и приложение телевизора различаются;
  фактическое состояние показывает `tv powerstate`.
- **Не печатаются русские буквы.** Раскладка системная: переключается кнопкой
  на пульте либо на странице поиска.

## Ограничения

- Управление телевизором только по сети; инфракрасного передатчика нет.
- Сон (S3) на этой плате не работает: вместо него выключение или экономия.
- Раскладка клавиатуры одна на всю систему.

## Краткий словарь

**Служба** — программа, работающая в фоне без окна и запускаемая системой.
**Юнит** — файл-описание службы для systemd.
**Пробуждение по сети (WoL)** — включение компьютера специальным сетевым пакетом.
**proxy-arp** — приставка отвечает на запросы адреса телевизора, чтобы тот
выглядел в домашней сети обычным устройством.
**SSAP** — протокол, которым телевизоры LG принимают команды по сети.
