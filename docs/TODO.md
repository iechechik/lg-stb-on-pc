# Что осталось сделать

Список живых задач проекта. Порядок — по важности для просмотра, а не по
сложности. Сделанное вычёркивать, а не удалять: по нему видно, что уже проверено
на живой приставке.

## 1. Режим 4K для фильмов (ждёт 4K-фильма в библиотеке)

Сейчас экран всегда 1920×1080 @ 60 Гц, и это правильный выбор: панель LG
49UK6450 физически 60 Гц (в EDID есть «120», но это TruMotion, а не панель),
поэтому 24p раскладывается по 60 обновлениям в любом случае, а рывки убирает
Real Cinema в настройках изображения телевизора.

4K имеет смысл только для файлов 2160p (4K UHD, 3840×2160) — тогда входной
сигнал действительно несёт больше точек. Для 1080p-фильма 4K24 не даёт ничего,
кроме дерганого интерфейса и лишнего мигания.

Что сделать, когда появится 2160p-фильм:

- В конфиг: `DISPLAY_UI="1920x1080@60"` и `DISPLAY_VIDEO="3840x2160@23.98"`.
  `DISPLAY_RATE` этим заменяется.
- Команда `stb screen ui|video`: `xrandr` с проверкой, что режим применился
  (`xrandr --query`), запись в `keys.log`/`system.log`.
- Переключение автоматическое, по признаку «у плеера есть играющий поток»
  (в PipeWire у потока состояние воспроизведения). Играет — `video`, пауза/стоп/выход — `ui`. Вручную
  ничего нажимать не нужно: фильмотека остаётся в 1080p60.
- Тот же признак «играет/пауза» нужен для гашения экрана во время фильма —
  делать один раз и использовать в двух местах.
- Если после переключения окно плеера не появилось за 20 с — вернуться на
  `ui` и записать причину, чтобы не остаться с чёрным экраном.
- Владелец предупреждён и согласен: при старте фильма экран мигнёт чёрным
  на 1–1,5 секунды (смена режима), после выхода вернётся.

Проверять на живом телевизоре: 2160p-файл играет, картинка на весь экран,
возврат на сетку — снова 1080p60 и гладкий курсор.

## 2. Экран гаснет, если ушёл во время фильма

Сейчас заставка считается простоем только по отсутствию ввода, поэтому кино
без нажатий приводит к чёрному экрану поверх фильма. Нужен признак
«играет/пауза» (тот же PipeWire-поток, см. пункт 1): играет — не гасим,
пауза — обычный отсчёт простоя.

## 3. Ввод текста в приложения телевизора — проверить в поле

Служба `com.webos.service.ime` работает по сети (проверено: `insertText`,
`deleteCharacters`, `sendEnterKey` отвечают `returnValue: true`). Ошибка была
наша: URI передавались со схемой, и телевизор отвечал 404.

Осталось проверить глазами: открыть на телевизоре поле поиска (чтобы появилась
клавиатура) и отправить `stb tv text "тест"`. Отдельно посмотреть приложения,
которые могут игнорировать клавиатуру webOS (часть сторонних, бывает YouTube),
и поле пароля (`hiddenText`).
