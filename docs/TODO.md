# Что осталось сделать

Список живых задач проекта. Порядок — по важности для просмотра, а не по
сложности. Сделанное вычёркивать, а не удалять: по нему видно, что уже проверено
на живой приставке.

## 1. Режим 4K для фильмов — СДЕЛАНО

Сначала экран стоял всегда 1920×1080 @ 60 Гц: панель LG 49UK6450 физически
60 Гц, 24p раскладывается по 60 обновлениям. Потом выяснилось, что на фильме
2160p картинка заметно чище, и режим сделали переключаемым.

Как устроено сейчас:

- ключ `JMP_VIDEO_4K` = `off` / `auto` / `all`; `all` — любой фильм, `auto` —
  только 4K-поток, `off` — всегда 1080p (и принудительно, а не «не трогать»);
- признак 4K — ширина кадра ≥ 3000 или высота ≥ 2000 (широкоформатные 3840×1600);
- опознание по серверу Jellyfin (`/Sessions`, ключ в `config/jellyfin.key`),
  лог плеера не используется;
- 2160p держится только при активном окне плеера; уход (Home, двойной Back) —
  сразу 1080p до показа сетки; на паузе режим не меняется;
- частота берётся из кадров фильма (23.976/24 → 23.98, 25 → 25 и так далее);
- управление: синяя кнопка пульта и `stb 4k`, статус — `stb status`;
- попутно: `JMP_SCALE` (масштаб интерфейса плеера), отключены `refreshrate.auto_switch`
  и CEC в плеере, буфер поднят до 1024.

Что осталось за пределами приставки: видеочип NUC (i3-5010U, Broadwell) не умеет
HEVC, поэтому 4K HEVC 10 бит идёт программно и рвётся. Плавно идут 4K-файлы в
H.264; альтернатива — транскод на сервере (владелец делает сам).

## 2. Экран гаснет, если ушёл во время фильма

Сейчас заставка считается простоем только по отсутствию ввода, поэтому кино
без нажатий приводит к чёрному экрану поверх фильма. Нужен признак
«играет/пауза» (тот же PipeWire-поток, см. пункт 1): играет — не гасим,
пауза — обычный отсчёт простоя.

## 3. Ввод текста в приложения телевизора — проверить в поле

Служба `com.webos.service.ime` работает по сети (проверено: `insertText`,
`deleteCharacters`, `sendEnterKey` отвечают `returnValue: true`). Ошибка была
наша: URI передавались со схемой, и телевизор отвечал 404.

Осталось проверить глазами: открыть на телевизоре поле поиска (чтобы появилась
клавиатура) и отправить `stb tv text "тест"`. Отдельно посмотреть приложения,
которые могут игнорировать клавиатуру webOS (часть сторонних, бывает YouTube),
и поле пароля (`hiddenText`).

## 4. Мелочи

- `stb-tv-boot` проверен только перезапуском юнита, не полной загрузкой коробки.
- Таймер скрытия приложения (10 минут) ни разу не проверялся вживую.
- Дрожание рамки на каждом втором нажатии стрелкой — было следствием ошибки в
  маршруте перестановки курсора, после починки не воспроизводится; если вернётся,
  проверять сначала ответ маршрута.
- Рефакторинг монолита выполнен: `bin/stb` 2748 → 1130 строк, разложен на
  `lib/stbcommon.py`, `lib/stbtvcmd.py`, `lib/stbdesktop.py`, `lib/stbactions.py`;
  поведение сверено по выводу команд, тесты и pyflakes зелёные.
