# Как менять плитки на сетке приставки

Файлы:     
| список плиток (порядок, иконки, команды) | `/opt/stb/config/tiles.json` |
| внешний вид (размеры, шрифты, цвета) | `/opt/stb/web/index.html` (блок `<style>`) |
| страница поиска (плитка «Браузер») | `/opt/stb/web/search.html` |
| картинки плиток | `/opt/stb/web/icons/` |

После правки `tiles.json` **перезагружать ничего не нужно**: страница сама
перечитывает список раз в минуту. Мгновенно — `Home`, затем Ctrl+R.

## Устройство одной плитки

```json
{
  "id": "sonarr",                        ← уникальное имя (для команд — адрес /run/<id>)
  "label": "Sonarr",                     ← крупная подпись
  "sub": "сериалы",                      ← мелкая подпись (можно убрать)
  "icon": "🗂",                          ← эмодзи-запасной, если нет картинки
  "img": "icons/sonarr.png",             ← картинка из /opt/stb/web/icons/
  "type": "url",                         ← "url" (открыть адрес) или "command" (выполнить)
  "target": "http://misc.chech:9095"     ← адрес или команда
}
```

## Порядок

Порядок на экране = порядок блоков в массиве. Поменять местами — просто
переставить блоки `{ ... },` в файле.

## Добавить
1. Скопировать любой блок и поправить поля.
2. `id` должен быть новым; для `command` — это имя, по которому вызывается
   `/run/<id>`.
3. Картинку положить в `/opt/stb/web/icons/` и указать `icons/имя.png`.

Примеры:

```json
{ "id": "kinopoisk", "label": "Кинопоиск", "icon": "🎬",
  "type": "url", "target": "https://www.kinopoisk.ru" },

{ "id": "stb box", "label": "На приставку", "icon": "🖥",
  "type": "command", "target": "stb box" }
```

## Удалить / скрыть

Удалить блок из массива или закомментировать. Комментарии // или /* ... */

## Проверить, что JSON не сломан

Комментарии `//` и `/* ... */`, а также висячие запятые допустимы, поэтому
`python3 -m json.tool` здесь не подходит — он на них ругается. Проверка проще:
перезагрузить страницу; при ошибке внизу экрана появится «не загрузились кнопки».

Если сломан — страница покажет ошибку внизу экрана («не загрузились кнопки»),
а сетка останется прежней из кеша.

## Размеры и шрифты (index.html)

Ищите в `<style>`:
- `.grid { ... gap: 20px; grid-template-columns: repeat(4, 1fr);` — число колонок;
- `a.tile { aspect-ratio: 1 / .78; }` — высота плитки (больше число — ниже плитка);
- `.ico { height: 112px; }` и `.ico img { width: 112px; }` — размер иконки;
- `.lbl { font-size: 28px; }` — подпись, `.sub { font-size: 17px; }` — подпись мелкая.

## Подтверждение опасных плиток

У плитки можно поставить признак `"confirm": true` — тогда перед выполнением
команда не запускается сразу, а открывается окно «<название плитки>?» с двумя
кнопками. Управление с пульта: влево/вправо — выбор, OK — действие, Back — отмена;
через 10 секунд окно закрывается само и ничего не делает. По умолчанию выбрана
«Отмена».

```json
{ "id": "stb-off", "label": "Выключить приставку", "confirm": true,
  "type": "command", "target": "/opt/stb/bin/stb poweroff --now" },

{ "id": "ui-restart", "label": "Перезапуск интерфейса", "confirm": true,
  "type": "command", "target": "/opt/stb/bin/stb ui restart" }
```

Так сейчас закрыты «Выключить ТВ», «Выключить приставку» и «Перезапуск
интерфейса»: последняя гасит плеер и чужие окна и поднимает браузер заново.

Заголовок окна и надпись на кнопке сейчас заданы в разметке общим текстом
(«Выключить?» / «Выключить»), поэтому у перезапуска надпись не совпадает с
названием плитки. Это недоделка страницы, а не свойство `confirm`.
