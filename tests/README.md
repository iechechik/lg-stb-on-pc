# Тесты приставки

Проверки не трогают телевизор, пульт и X: всё, что нужно от внешнего мира,
подменяется. Тесты можно гонять на любой машине, где лежит `/opt/stb`.

## Как запускать

```sh
sudo /opt/stb/tests/run_tests.sh      # тесты + pyflakes + shellcheck
sudo python3 -m pytest /opt/stb/tests # только тесты
sudo python3 -m pytest /opt/stb/tests/test_watch.py -q   # один файл
```

`run_tests.sh` — единственная точка входа: он же проверяет `pyflakes`
(неопределённые и неиспользуемые имена) и `shellcheck` (warning и выше).
Код возврата ненулевой, если что-то не так — этим пользуется приёмка.

## Что где лежит

| `test_watch.py` | сторож: решение «включён/выключен», свежесть по полям, общий клиент демона, уборка плеера, безопасный отказ диагностики |
| `test_marks.py` | отметки (`mark_set/read/clear/age`) и запрет самовызова функций |

| `test_windows.py` | предикаты окна: сетка, браузер, наше окно, приложение |
| `test_buttons.py` | карты кнопок (`config/buttons-*.conf`) ↔ маршруты `lib/stbkeys.py` ↔ список действий `stb key` |
| `test_tvlast.py` | память «что показывал телевизор»: чужое приложение запоминается, наш вход — нет; плитка берёт запомненное, без памяти — запасное |
| `test_gesture.py` | кнопки с выдержкой: окно и склейка из конфига, одиночное/двойное/тройное нажатие, новая кнопка одной строкой в `GESTURES` |
| `test_back_split.py` | Back разделён на одиночный и двойной: специфика по режимам и окнам осталась в обработчиках, распознавание — одно, прочие кнопки без ожидания |
| `test_ws.py` | кадры WebSocket: фрагменты, управляющие кадры внутри сообщения, обрыв посреди сообщения |
| `test_tv_text.py` | ввод текста: разбор аргументов (`--delete`, `--enter`, `--`) и буфер накопления |
| `test_fake_tv.py` | приёмник пульта: SSDP-ответ, регистрация, канал кнопок |
| `test_config_vars.py` | каждая переменная, которую читает код, описана в `config/stb.conf` |
| `test_json_preprocess.py` | препроцессор `tiles.json`: комментарии и запятые не ломают разбор |
| `test_docs.py` | документы не расходятся с системой: `COMMANDS.md`, пути, юниты, параметры |
| `test_sources.py` | в исходниках нет вписанных адресов, прибитой версии Python, чужих домашних каталогов и `\${X:=\${X}}` |
| `test_installer.py` | `install.sh --check`: список файлов и пакетов на месте |
| `conftest.py` | общие фикстуры: `faketv`, `stbweb`, `tvtext`, загрузчик модулей без расширения |
| `fake_tv.py` | поддельный телевизор для замеров вручную (SSAP-заглушка) |
| `bench_consumers.py` | замер стоимости опроса сторожей: CPU и процессы (не тест, запускается руками) |

## Как писать новый тест

1. **Ничего живого.** Телевизор и X не нужны: подменяйте `daemon_ask`,
   `subprocess.run`, `as_user` через `monkeypatch`.
2. **Модуль грузится по пути** — скрипты приставки без расширения `.py`:

   ```python
   loader = importlib.machinery.SourceFileLoader("stbwatch", os.path.join(ROOT, "bin/stb-watch"))
   spec = importlib.util.spec_from_loader("stbwatch", loader)
   module = importlib.util.module_from_spec(spec)
   loader.exec_module(module)
   ```

   Имя модуля должно быть уникальным: два теста с одним именем подменяют
   друг друга в `sys.modules`.
3. **Файл — по теме, а не по дате.** Название отвечает на вопрос «что
   сломается», а не «когда писали». `test_round3.py` — пример того, как не надо.
4. **Каждая починка — с тестом.** Ошибка, найденная на живом железе, обязана
   оставить после себя проверку: иначе она вернётся.
5. **Проверяйте причину, а не текст.** Сравнивать сообщения журнала стоит
   только там, где формат — контракт (`test_logs.py`); в остальных случаях
   проверяйте решения и аргументы вызовов.

## Осознанные послабления

- **Кадры WebSocket не проверяются на маску и RSV-биты.** Единственный клиент —
  приложение-пульт, и оно работает; если оно присылает немаскированные кадры,
  строгая проверка не повысит надёжность, а отключит пульт. Проверяется то, что
  действительно опасно на приставке: размер кадра и утечка состояния сборки.
- **`tests/test_docs.py` ищет в документах только то, что можно сверить
  автоматически** (команды, пути, юниты, параметры, журналы). Смысл текста
  проверяет человек.

## Границы

- Тесты не запускают службы, не пишут в `/var/log/stb` и не перезапускают
  браузер. Всё, что пишет файлы, пишет во временный каталог (`tmp_path`).
- Замеры и проверки на живом железе — отдельно: `bench_consumers.py` и ручные
  прогоны после выката. Здесь только то, что можно проверить без телевизора.
